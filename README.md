## Overview
`Stellarcontract-network/Stellar-Front` provides the official open-source user interface for the Stellar Gaming Hub ecosystem. Built with **Next.js**, **TypeScript**, and **Tailwind CSS**, this frontend allows players to connect their wallets, manage assets, interact with verified game sessions, and explore developer rewards.

## Core Features
- **Web3 Wallet Integration:** Seamless connection supporting MetaMask, WalletConnect, and Coinbase Wallet.
- **Game Session Dashboard:** Real-time state tracking for active game sessions, directly integrated with the Stellar Gaming Protocol.
- **Creator Funding Portal:** Direct visibility into Drips Protocol reward streams for verified game developers.
- **Responsive UI:** Optimized for desktop and mobile gaming experiences.
