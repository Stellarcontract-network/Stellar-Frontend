## Overview
`Stellarcontract-network/Stellar-Front` provides the official open-source user interface for the Stellar Gaming Hub ecosystem. Built with **Next.js**, **TypeScript**, and **Tailwind CSS**, this frontend allows players to connect their wallets, manage assets, interact with verified game sessions, and explore developer rewards.
