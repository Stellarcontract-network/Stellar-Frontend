## 🌟 Overview

**Stellar-Frontend** is the official web interface and client portal for the Stellar Gaming & API ecosystem. Built with Next.js, TypeScript, and Tailwind CSS, it provides a high-performance, responsive UI for users to explore game services, interact with client APIs, and manage account preferences.

---

## 🚀 Features

- **Client Dashboard:** Real-time metrics, user profile management, and session logs.
- **Game Ecosystem Portal:** Interactive navigation for hosted titles and services.
- **API Sandbox:** UI environment to inspect and test backend API responses.
- **Responsive Theme:** Fully optimized across desktop, tablet, and mobile views.

---

## 🛠 Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS & Lucide Icons
- **State & Data Fetching:** React Query / Native Fetch
